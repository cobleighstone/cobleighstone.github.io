# Abbey Rose Cobleigh — Personal Website

A complete, ready-to-host website made of plain static HTML/CSS/JS.
No build step, no server, no database. Just upload it.

## Files
- `index.html` — Home / About (loads first)
- `academics.html`, `projects.html`, `album.html`, `resume.html` — other pages
- `assets/` — stylesheet, script, and images

## How to publish on GitHub Pages (free)
1. Make a free account at github.com.
2. Create a new repository named exactly `YOURUSERNAME.github.io`
   (replace YOURUSERNAME with your GitHub username). Keep it Public.
3. On the repo page: "Add file" -> "Upload files" -> drag in EVERYTHING
   from inside this folder (the .html files AND the assets folder).
   Important: index.html must sit at the top level of the repo, not
   inside a subfolder. Click "Commit changes".
4. Go to Settings -> Pages. Under "Branch", choose `main` and `/ (root)`,
   then Save.
5. Wait 1-2 minutes, then visit https://YOURUSERNAME.github.io

## Note
The fonts load from Google Fonts over the internet, which is normal and
works fine once the site is hosted. Everything else is included here.
